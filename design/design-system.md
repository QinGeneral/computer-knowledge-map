# 视觉与内容规范

参考：design/concept.png；沿用精英日课知识地图的绿色阅读系统。

- 页面 #f5f7f5、面板 #fff、主文字 #203832、次文字 #647770、强调 #176857、分隔线 #dfe7e2。
- 桌面：顶部品牌 + 下载；第二行三视图页签；左侧 250px 领域导航；主体开放式领域列表 + 计算机层次图；下方专题扩展。
- 中文标题使用 Songti SC / Noto Serif CJK SC；正文及控件使用系统无衬线。标题 28–48px，正文 14–16px，导航 15px，次要文字 12–13px。
- 面板圆角 8px，按钮 6px；轻边框，无渐变；图标使用原生 SVG 线性图标。
- 手机：顶部缩排，领域导航改为下拉框；列表单列；层次图在列表后，详情与原图为全屏对话框。
- 首页文字白名单：品牌、原有副标题、三视图、下载知识地图、领域名称、连接计算机知识的每一层、从硬件到系统，从算法到应用。按结构探索，回到原图核对。、搜索占位、源图提炼的领域说明、计算机的知识层次、层次图的原图标签、从总览开始、让知识继续生长、两个专题名称与等待提示。
- 内容优先于生成概念图的细节：常用数学说明改为原图实际包含的应用方向；知识层次底部补齐显示器/键盘；不把系统软件的概念线条当成计算机真实调用图。
- 功能要求：搜索、领域筛选、知识树递归展开/收起、节点详情、来源照片局部、原图缩放、Markdown/JSON 导出、URL 深链接与后退。
- 后续专题采用独立 id、status、relatedDomains、roots、photos；当前明确标为 planned，不虚构内容。
