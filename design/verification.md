## 浏览器与视觉

使用 Codex 内置浏览器（CUA 的 IAB）；未采用 Playwright 外部浏览器替代。通过内置浏览器提供的 Playwright 定位接口执行控件操作，截图由内置浏览器保存。桌面视口 1536×1024，与概念图同尺寸；另验 390×844 手机视口与默认浏览器尺寸。已使用 `view_image` 直接查看概念与最终桌面、手机截图。

| 比对点 | 概念 / 实现 | 处理结果 |
| --- | --- | --- |
| 页面框架 | 白色双行页头、258px 领域侧栏、开放式主列表、右侧层次图 | 保留框架；无额外营销区块 |
| 色彩 | #f5f7f5 底色、#fff 面板、#176857 强调、#dfe7e2 分隔 | 计算样式确认底色 rgb(245,247,245)；无渐变与照片蒙层 |
| 字体 | 中文宋体主标题、系统无衬线导航、大小层级分明 | 控件明确字号，首屏标题 48px、领域标题 22px |
| 列表密度 | 七领域纵向列表、编号与标题、说明、右箭头 | 缩短初版行高，保持七行与扩展区在桌面首屏的节奏 |
| 知识层次图 | 绿色连接线与原生按钮 | 修复初版顶部空隙与“计算机网络”换行；按原图补齐显示器/键盘 |
| 首屏文案 | 品牌、视图名、搜索、领域、扩展入口 | 无白名单外营销文字；领域描述依据照片更正，不采用生成图虚构的数学分类 |
| 手机 | 领域下拉、单列列表、全屏详情 | 修复下载按钮在窄屏保留文字的问题；无横向溢出 |
| 来源图片 | 保留原始照片，不用概念图充当界面 | 详情局部从实际 JPEG 绘制，可打开完整照片 |

修复过：领域切换保留旧滚动位置、桌面列表过高、层次图文字换行、窄屏下载按钮、极小的 OCR 负坐标。生成概念图和实际界面的一致性已逐项核对；无未解决的可修复视觉缺陷。允许的差异：按来源修改领域说明、补齐显示器/键盘、连接线用层次示意表达、增加底部真实数据与导出链接；全部出于内容保真和功能需要。

## 交互路径

- 首页全站检索 TCP → 27 条上下文结果 → 计算机网络中的 TCP → 来源照片局部 → 打开完整图 → 缩放比例变化。
- 手机领域切到数据结构与算法 → 全部展开（47 个分支全部打开）→ 检索二分查找 → 5 个上下文结果 → 详情展示子节点、面包屑与照片。
- 编译原理入口 → 明确等待图片 → 已有计算机组成原理 → 原图资料仅显示该领域 3 张照片。
- 浏览器原生日志检查：无 error / warn。
- 桌面及手机 DOM 宽度检查：无横向溢出。
- 原生 dialog 支持 Escape 关闭、按钮关闭与焦点约束；条目路由在 hash 中可复制。

## 数据与扩展

`python3 scripts/validate_data.py` 通过：7 领域、798 条目全部可达，15 张 JPEG 与来源清单哈希一致；722 条目带 OCR 定位，其余显示完整图。校验父子关系、唯一 id、领域计数、图片引用与 Markdown 导出条目数。OCR 定位不构成逐字识别准确性的保证。
